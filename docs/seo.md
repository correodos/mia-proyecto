# SEO

## Objetivo SEO

Conseguir tráfico orgánico mediante herramientas útiles y contenido que responda a necesidades reales de búsqueda.

El SEO debe apoyar al producto, no determinar por sí solo qué se construye.

## Principios

- No crear páginas únicamente para repetir una keyword.
- No generar contenido masivo y repetitivo.
- No copiar contenido de otras webs.
- No inventar volúmenes de búsqueda, CPC ni tráfico.
- Diferenciar siempre entre datos comprobados, estimaciones e hipótesis.
- Cada página debe tener una intención clara.
- Agrupar variantes de una misma intención cuando una única página pueda resolverlas correctamente.
- Priorizar herramientas útiles frente a páginas puramente informativas.

## Investigación de keywords

Antes de crear nuevas páginas se estudiarán, cuando sea posible:

- demanda;
- país;
- intención de búsqueda;
- competencia;
- características de la SERP;
- dificultad;
- oportunidad de diferenciación.

Los datos de herramientas SEO de terceros deberán tratarse como estimaciones y no como datos absolutos.

## Estructura de contenidos

La arquitectura debe organizarse alrededor de temas y necesidades.

Ejemplo:

- calculadora de horas trabajadas;
- cálculo entre dos horas;
- suma y resta de tiempo;
- horas decimales;
- jornadas;
- turnos.

Los contenidos informativos deben complementar las herramientas.

Ejemplo:

Una guía sobre horas decimales debe enlazar a la herramienta de conversión correspondiente.

## SEO técnico

La web deberá cuidar:

- títulos;
- meta descriptions;
- encabezados;
- URLs;
- enlaces internos;
- sitemap;
- robots.txt;
- canonical;
- datos estructurados cuando sean apropiados;
- rendimiento;
- experiencia móvil;
- accesibilidad.

No añadir elementos SEO sin una razón clara.
