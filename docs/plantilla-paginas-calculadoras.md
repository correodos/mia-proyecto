# Plantilla de estructura — Páginas de calculadoras

## Objetivo

Todas las páginas de calculadoras deben seguir una estructura común para que la web mantenga una presentación clara, coherente y fácil de entender.

El contenido de cada calculadora será específico, pero la estructura general debe mantenerse.

---

## 1. Título

La página debe comenzar con un único título principal (H1).

El título debe indicar claramente qué calcula la herramienta.

Ejemplo:

> Calculadora de horas trabajadas

---

## 2. Descripción breve

Justo debajo del título debe aparecer una descripción breve de la calculadora.

Debe explicar de forma sencilla:

- qué calcula;
- para qué sirve;
- y, cuando sea necesario, qué datos necesita el usuario.

Debe ser breve y no convertirse en una explicación extensa.

Ejemplo:

> Calcula las horas trabajadas de una jornada a partir de la hora de entrada, la hora de salida y el tiempo de descanso.

---

## 3. Calculadora

Después de la descripción breve debe aparecer la calculadora.

Esta debe ser el elemento principal de la página.

Aquí se incluirán únicamente los elementos necesarios para realizar el cálculo:

- campos;
- opciones;
- botones;
- resultados;
- mensajes de validación.

No deben aparecer aquí explicaciones largas, ejemplos, FAQ ni contenido adicional que pueda distraer del cálculo.

---

## 4. Cómo calcular

Después de la calculadora aparecerá la explicación de cómo realizar el cálculo.

Esta sección debe explicar de forma sencilla el funcionamiento de la herramienta.

Puede incluir:

- explicación de los datos;
- pasos para realizar el cálculo;
- fórmula utilizada, cuando sea útil;
- aclaraciones sobre el funcionamiento.

El contenido debe ser específico de cada calculadora.

---

## 5. Ejemplo

Después de "Cómo calcular" aparecerá un ejemplo práctico.

El ejemplo debe utilizar datos reales o fácilmente comprensibles y mostrar cómo se obtiene el resultado.

Debe corresponder exactamente con el funcionamiento de la calculadora.

Ejemplo:

> Entrada: 09:00  
> Salida: 17:30  
> Descanso: 30 minutos  
>
> Resultado: 8 horas trabajadas.

---

## 6. Información adicional

Este apartado será opcional.

Solo se incluirá cuando exista información útil que ayude al usuario a comprender mejor la calculadora o sus resultados.

Puede incluir:

- casos especiales;
- aclaraciones;
- situaciones habituales;
- conversiones;
- información relacionada con el cálculo.

Si no aporta valor, no se incluye.

---

## 7. Preguntas frecuentes

Este apartado será opcional.

Se incluirá cuando existan preguntas habituales relacionadas con la calculadora.

Las preguntas y respuestas deben ser breves, claras y específicas.

No se utilizará esta sección para añadir contenido innecesario.

---

## 8. Contenido relacionado

Al final de la página se podrán mostrar enlaces a contenidos relacionados.

Pueden ser:

- otras calculadoras;
- guías;
- explicaciones relacionadas.

Los enlaces deben ser relevantes para el usuario.

---

# Orden definitivo

La estructura estándar será:

1. **Título**
2. **Descripción breve**
3. **Calculadora**
4. **Cómo calcular**
5. **Ejemplo**
6. **Información adicional** *(opcional)*
7. **Preguntas frecuentes** *(opcional)*
8. **Contenido relacionado**

---

# Regla para nuevas calculadoras

Toda nueva calculadora deberá utilizar esta estructura como base.

El contenido será diferente para cada herramienta, pero el orden general de la información deberá mantenerse.

No se deberá colocar "Cómo calcular", "Ejemplo" u otro contenido explicativo antes de la calculadora salvo que exista una razón específica para hacerlo.
