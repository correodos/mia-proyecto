## 2. Qué datos personales se recopilan

Miaherramienta.com está diseñado para poder utilizar sus calculadoras sin necesidad de crear una cuenta ni facilitar datos personales directamente.

Los datos introducidos en las calculadoras, como horarios, horas de entrada, horas de salida o descansos, se utilizan para realizar los cálculos solicitados por el usuario.

Estos datos no se envían al titular del sitio web ni se almacenan en una base de datos propia.

Actualmente, el sitio web no dispone de formularios de registro, cuentas de usuario ni formularios destinados a recopilar datos personales.

## 3. Finalidad del tratamiento

Cuando el usuario presta su consentimiento para las cookies de análisis, determinados datos técnicos y de navegación pueden ser tratados con la finalidad de:

- Conocer cómo se utiliza el sitio web.
- Analizar el tráfico y las visitas.
- Detectar posibles problemas técnicos.
- Mejorar el funcionamiento, contenido y estructura del sitio.
- Obtener estadísticas generales sobre el uso de las herramientas.

Estos datos se utilizan con fines estadísticos y de análisis del funcionamiento del sitio web.

## 4. Base jurídica

La base jurídica para el uso de cookies y tecnologías de análisis es el consentimiento del usuario.

El usuario puede aceptar o rechazar las cookies de análisis mediante el sistema de consentimiento disponible en el sitio web.

Las cookies estrictamente necesarias para el funcionamiento de determinadas funciones del sitio no requieren consentimiento cuando resulten necesarias para prestar el servicio solicitado.

## 5. Google Analytics

Miaherramienta.com utiliza Google Analytics, un servicio de análisis web proporcionado por Google.

Google Analytics permite obtener información estadística sobre el uso del sitio web, como visitas, páginas consultadas, dispositivo utilizado y otra información relacionada con la navegación.

Google Analytics se configura de forma que las funciones de análisis que requieren consentimiento no se activen hasta que el usuario haya aceptado las cookies de análisis.

El usuario puede modificar o retirar posteriormente su consentimiento mediante el enlace **“Configurar cookies”** disponible en el sitio web.

Para obtener información adicional sobre el tratamiento de datos realizado por Google, puedes consultar la información proporcionada por Google sobre sus servicios de medición y privacidad.

## 6. Conservación de los datos

El titular no almacena en sus propios sistemas los datos introducidos por los usuarios en las calculadoras.

En el caso de los datos tratados mediante herramientas de análisis, su conservación se realiza conforme a la configuración y políticas del servicio utilizado.

El titular revisará periódicamente la configuración de estos servicios para mantenerla de acuerdo con las necesidades del sitio web y la normativa aplicable.

## 7. Destinatarios de los datos

El titular no vende ni cede datos personales de los usuarios a terceros con fines comerciales.

Cuando se utilizan servicios de terceros, como Google Analytics, determinados datos técnicos y de navegación pueden ser tratados por dichos proveedores para prestar sus servicios.

El tratamiento realizado por estos proveedores se encuentra sujeto a sus propias condiciones y políticas de privacidad.

## 8. Transferencias internacionales

Algunos proveedores tecnológicos utilizados por el sitio web pueden realizar tratamientos de datos desde países situados fuera del Espacio Económico Europeo.

Cuando se produzcan transferencias internacionales de datos, estas deberán realizarse conforme a los mecanismos y garantías establecidos por la normativa aplicable en materia de protección de datos.

En particular, Google dispone de mecanismos específicos para las transferencias internacionales de datos en relación con sus servicios.

Si el usuario considera que el tratamiento de sus datos personales no se ajusta a la normativa aplicable, puede presentar una reclamación ante la autoridad de control competente.

En España, la autoridad de control en materia de protección de datos es la **Agencia Española de Protección de Datos (AEPD)**.

El titular adopta medidas técnicas y organizativas razonables destinadas a proteger la información tratada a través del sitio web frente a accesos no autorizados, pérdida, alteración o utilización indebida.

No obstante, ningún sistema conectado a Internet puede garantizar una seguridad absoluta.
