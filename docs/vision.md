# Visión del proyecto

## Qué estamos construyendo

Estamos creando una web en español de herramientas online gratuitas para calcular y organizar horas y tiempo, con especial atención a situaciones relacionadas con trabajo, jornadas y turnos.

La web debe permitir al usuario resolver rápidamente cálculos que normalmente haría manualmente, sin necesidad de registrarse ni instalar nada.

La herramienta principal será una calculadora de horas trabajadas, acompañada por otras herramientas relacionadas.

## Problema que queremos resolver

Calcular horas y jornadas puede resultar incómodo cuando existen descansos, varios tramos de trabajo, horarios que cruzan medianoche o necesidad de convertir entre diferentes formatos de tiempo.

La web debe convertir estos cálculos en algo sencillo:

introducir datos → calcular → obtener un resultado claro.

## Usuario objetivo

Personas hispanohablantes que necesitan calcular:

- horas trabajadas;
- duración entre horarios;
- jornadas partidas;
- turnos;
- descansos;
- horas semanales;
- horas en formato decimal;
- otros cálculos relacionados con el tiempo.

La web no estará limitada inicialmente a un único país.

## Propuesta de valor

La web debe ser:

- gratuita;
- rápida;
- sencilla;
- clara;
- usable desde móvil;
- accesible sin registro;
- útil incluso para usuarios con pocos conocimientos.

La prioridad es resolver correctamente el problema, no llenar la página de funcionalidades innecesarias.

## Principios

1. La utilidad para el usuario está por encima del SEO.
2. Cada herramienta debe resolver una necesidad real.
3. No crear páginas duplicadas únicamente para posicionar variantes de keywords.
4. No copiar contenido ni funcionalidades de otros sitios.
5. No inventar datos.
6. Separar claramente cálculos matemáticos de información legal o normativa.
7. Priorizar velocidad, accesibilidad y experiencia móvil.
8. Mantener la arquitectura sencilla y fácil de mantener.
9. Añadir nuevas funcionalidades basándonos en necesidades reales y datos obtenidos después del lanzamiento.

## Modelo de negocio

La monetización inicial será principalmente mediante Google AdSense.

La web no debe diseñarse alrededor de los anuncios. El usuario debe poder utilizar las herramientas cómodamente y los anuncios deben integrarse sin interferir con la funcionalidad principal.

En fases posteriores podrán estudiarse otras formas de monetización si el tráfico y el producto lo justifican.

## Visión a largo plazo

Convertir el proyecto en una referencia de herramientas sencillas para resolver problemas relacionados con horas, tiempo, jornadas y turnos en español.

El proyecto deberá crecer progresivamente a partir de:

- nuevas necesidades detectadas;
- consultas reales de búsqueda;
- comportamiento de los usuarios;
- funcionalidades que aporten utilidad real.
